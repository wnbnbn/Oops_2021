# LocalFeed v0.9.5 闪卡可见性修复验收

版本：0.9.5，versionCode 23。视频播放器、Feed 队列、媒体扫描、收件箱和删除任务核心未改。

## 修复内容

- 独立“查看闪卡”页强制启用完整闪卡材质。即使图片没有点赞、仍是普通卡，也会显示彩虹光泽、foil 斜纹和局部高光。
- 页面静置时自动进行约 2.8 秒的缓慢往返扫光，让用户进入页面后能直接判断特效是否生效。
- 手指按下卡面后，自动扫光停止，光泽和倾斜跟随手指；松手回正后恢复自动扫光。
- 闪卡容器设为可点击，以保证内部 ImageView 没有监听器时仍能持续收到 MOVE 和 UP 事件。
- 卡牌大厅的对战卡保持原来的触摸驱动，不开启待机动画，避免同时绘制多张动态卡。

## 必须真机检查

1. 找一张零点赞普通图片进入“查看闪卡”，不触摸屏幕，确认彩虹光泽会自行横向扫过。
2. 手指按住卡面并移动到四角，确认光斑连续跟随，没有只响应第一次按下的情况。
3. 松手后检查卡面平滑回正，并重新开始自动扫光。
4. 分别用横图、竖图和 GIF 检查前景显示、背景模糊和动画帧率。
5. 在锦标赛中轻点选胜者、长按预览，确认既有手势没有被闪卡触摸观察器破坏。
6. 快速反复进入、退出闪卡页，确认动画及时释放，没有闪退或退出后持续耗电。

CI 验证触控坐标、待机轨迹边界、Android 编译、源码完整性和固定签名。材质亮度与真机 GPU 流畅度仍以 OnePlus Ace 6 实测为准。
