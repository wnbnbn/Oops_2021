# LocalFeed v0.9.4 闪卡试用版验收

版本：0.9.4，versionCode 22。视频播放器、Feed 队列、随机权重、收件箱和删除任务核心未改。

## 实现

- `HoloCardView` 观察外层触控但不夺走点击和长按，按卡面坐标驱动 5.5° 内的倾斜、彩虹反光、斜纹与径向高光，松手 360 ms 回正。
- 普通、铜、银、金、幻彩、典藏采用同一金属框结构，通过材质配色和高光强度区分；界面不再显示等级文字。
- 相册仅绘制静态边框。锦标赛和生存擂台同时最多让两张对战卡运行动态层；记忆配对卡保持静态。
- 独立页面采用固定 5:7 外框。前景图片可在 CENTER_CROP 与 FIT_CENTER 间切换；全屏背景使用同图铺满，Android 12 以上加入系统模糊，较低版本使用暗化兼容。
- 横图、方图和长图的原始比例不会改变；铺满允许裁切，完整显示保留全部内容。GIF 继续由现有 ImageDecoder/AnimatedImageDrawable 加载。

## 入口

- 单图或瀑布流的图片更多菜单 → 查看闪卡。
- 卡牌长按预览 → 更多 → 查看闪卡。
- 锦标赛或生存擂台结束后点击冠军卡。
- 战绩中的“查看胜者”。

## 必须真机检查

1. 分别使用竖图、横图、方图和超长图，检查铺满/完整图标切换及模糊背景。
2. 在卡面四角和中心移动手指，检查高光位置、倾斜方向及松手回正。
3. 确认拖动不会直接选出获胜卡；正常轻点图片仍能投票，长按仍打开原图预览。
4. 使用普通、铜、银、金、幻彩、典藏各一张，重点判断幻彩和典藏是否有闪卡质感。
5. 快速反复进入和退出闪卡页，确认无黑图、残留动画和闪退。
6. GIF 在独立页能否播放；同时观察 GIF 与反光叠加是否掉帧。
7. 相册缩略图没有红心和等级文字，视频时长、收藏星星、问题标记仍正常。

CI 只能验证 Kotlin 状态映射、Android 编译、源码完整性和固定签名。卡牌材质审美、触控手感和真实设备 GPU 性能必须由真机反馈决定。
