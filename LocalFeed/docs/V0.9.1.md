# LocalFeed v0.9.1

## 修改范围

收件箱通用诊断与副本恢复；任务中心完整详情；卡牌尺寸与双图布局。未修改视频播放池、FeedAdapter、图片阅读器或点赞/收藏规则。

## 收件箱问题与修正

v0.9.0 从日志恢复副本后使用 DocumentFile.fromSingleUri 包装，却调用该对象不支持的 renameTo。UnsupportedOperationException 可能没有 message，旧错误处理因此仅显示“转移失败”。改为从用户选择的目标目录取得可重命名的子文档对象。此修正适用于全部收件箱目录，不针对 Telegram 写特例。

每个目录和文件产生独立 InboxEvent，单文件更新同一条任务。包含授权检查、读取属性、稳定检测、日志恢复、来源校验、临时副本检查、复制、校验、重命名、删除来源、完成记录。第一次发现/文件变化显示等待，不当作失败。异常保留类型、文字消息和最多六层 cause；无消息时明确提示，仍保留失败阶段。

校验完整的旧临时副本直接复用；归档后删除来源失败显示“已归档 · 来源待删除”，下一次扫描复核后重试删除。发现文件冲突或来源改变保留来源与已有副本，不覆盖。创建 .nomedia 的失败不阻断其他有效转移。

## 任务中心

点击任何任务可阅读完整、可选中的详细文本并复制。中断后保留上次阶段与原因。收件箱持久化/事件处理在扫描工作线程执行，UI 仅收到任务快照。历史裁剪优先移除完成/失败记录，不能挤掉正在运行或排队的永久删除任务。旧版本已经丢失的错误文字不能追溯恢复；重新执行后可产生新诊断。

## 卡牌

图片完整适配可用区域，边框贴近图片，仅留 3dp 内衬，外围透明。清除卡背按钮的主题背景 tint，避免自定义卡背被系统染成白块。锦标赛/擂台首次采用按实际展示面积选择的双图布局，整局保持固定；按钮可切换上下/左右并记住选择。记忆配对保持网格，使用相同的贴图边框。预览使用深色背景，关闭后取消图片加载。

## 自动化与实机边界

增加纯 Kotlin 几何测试：竖图、横图、极端比例、未知比例、可用边界、布局选择。收件箱状态机使用明确标注的模拟文档提供器测试等待、成功转移、拒绝重命名后恢复、来源删除失败后恢复、磁盘写入失败、复用副本且不重复复制。模拟提供器不等价于真实 SAF 权限、不同提供器 URI 改变、Android 进程死亡或手机视觉验收。

当前工作环境不可用，不能在本地运行 Android 或截图；源码通过 GitHub 读取/提交，编译、状态机回归和固定签名由 CI 验证。手机视觉和实际来源/归档目录仍需实机确认。版本发布保持正式 Release 和正常应用内更新入口。
