# LocalFeed v0.9.0

## 本轮范围

下载收件箱；独立图片卡牌大厅；8/16/32 强锦标赛；4×4、5×4 记忆配对；生存擂台；最近 200 局战绩与简易图鉴。

视频播放池、FeedAdapter、图片阅读器、原点赞与收藏规则保持不变。不实现混合 Feed、健康中心、复杂卡牌战斗或归档分类。

## 入口与操作

媒体库工具新增「卡牌大厅」「下载收件箱」。大厅默认全部图片，也可选择收藏或已导入根目录。卡牌点击选择，长按打开可缩放预览。游戏结果独立保存，不影响点赞、随机权重或文件内容。锦标赛完成后记录冠军；擂台允许中途结束并保存已发生的对决；记忆配对完成后记录翻牌次数与用时。

## 收件箱

用户选择来源与归档目录并确认转移授权。归档目录自动加入媒体库；可配置多条规则，可暂停或移除规则，移除不删除文件。当前仅处理来源目录直接包含的视频与图片，不递归处理子目录。

跟随既有手动/启动/返回应用扫描执行；不是系统后台常驻服务。首次发现文件只记录大小与修改时间；下一次扫描在至少 30 秒后仍稳定才转移，尚未稳定的文件留在来源。跳过临时扩展名和零字节文件。

复制使用持久化临时文件与转移日志；校验长度与 SHA-256；完成后重命名，同名不覆盖；删除来源前再次验证来源未变化与副本完整。来源删除失败会保留日志，后续扫描重试。不进行自动转码或删除损坏媒体。

收件箱与删除共享 MediaRepository 存储锁，不能同时修改文件。每个成功/失败文件进入已有任务中心。转移等待会延后索引开始，但不阻塞 UI 线程。大文件多次读校验会增加 I/O；安全优先，后续根据实机反馈再优化。

## 实现定位

- core/CardGames.kt：纯 Kotlin 状态机。
- ui/CardHallActivity.kt：独立 Activity，大厅、对局、预览、战绩。
- data/DownloadInbox.kt：规则、稳定检测、校验、持久化转移日志。
- MediaRepository.scanAll：存储锁内执行收件箱，再进行既有扫描。
- MainActivity：仅新增入口、SAF 目录选择、转移结果写入任务中心。

## 验收与已知限制

纯 Kotlin 回归增加淘汰赛全部规模、擂主更替、重复翻牌与错配锁定。Android 编译由 CI 验证。手机触控、界面排版、不同 SAF 提供器的重命名/断电恢复、Telegram 写入中途的行为仍需实机验证，不能仅凭编译通过认定这些项目已通过。

当前对局退出不自动保存未完成锦标赛/配对；战绩保留最近 200 局，图鉴统计基于这些战绩；没有永久生涯累计或完整对阵图。游戏不自动增加点赞或收藏。
