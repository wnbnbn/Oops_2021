# v0.6 测试说明

本次自动门禁：完整源文件 SHA256/严格 UTF-8、Random Feed V2、FeedSession、AlbumQuery、缓存相似扫描 smoke、真实 Android assembleDebug、APK 固定签名证书、APK SHA256、构建产物上传。

实际运行结果以对应 commit 的 GitHub Actions 日志和 artifacts 内 BUILD_REPORT.txt 为准。Scanner smoke 使用 Android/数据库测试桩，仅证明算法与缓存控制流程；真实 APK 编译使用 Android SDK。

待真机：OnePlus Ace 6 / ColorOS 16 慢速跟手拖动、快速连续 30+ 次、后台返回后拖动进度条、连续多次双击、永久删除当前视频、横竖切换、再次长按下滑取消 2×；检查首帧跳变、黑洞、误暂停、音质和队列复活。

0.6.0 使用相邻页底层首帧解决慢拖纯黑空洞；播放器真正出帧后才隐藏。扫描改为增量分析并在后台返回时自动检查，最终状态明确区分新增、更新和失败。仍不能用编译结果代替真机播放、SAF 删除和千级目录验收。
# v0.6.1 修复验证

- CI 必须通过源码完整性、纯 Kotlin 回归、Android assemble、固定签名和证书指纹校验。
- 真机重点：横屏左上角返回始终可见；右侧按钮明显上移；短视频重新进入从头播放。
- 真机重点：倍速下滑取消后页面不产生任何跟随位移。
- 重复扫描时立即删除普通图片，确认删除不被扫描任务阻塞；重复项默认自动勾选且失败项保留。
- 问题媒体执行全面诊断，确认具体原因可见；图片查看页删除、连续阅读失败提示、单图切回和当前图片定位均需验证。

# v0.6.2 修复验证

- CI 必须通过源码完整性、纯 Kotlin 回归、Android assemble、固定签名和证书指纹校验。
- 真机重点：随机相册在扫描/点赞后顺序不变，瀑布流无大跳；双击、捏合、拖动后仍能退出并定位中央图片。
- 真机重点：锁定 2× 后再次长按下滑确实恢复用户速度，抬手不会带动 ViewPager。
- 问题视频必须停在当前页并显示原因；外部打开、删除、问题筛选以及已确认/待确认标签均需验证。
- 任务中心需验证千级扫描、重复检查与批量删除并行时的状态、历史和缩略图；播放页不得出现扫描 Toast。

# v0.6.3 修复验证

- 排序后必须自动到首项；从任意筛选/排序结果打开中间视频，连续下滑必须严格跟随相册可见顺序。
- 任务中心包含已删除或失效文件记录时仍可打开；历史缩略图加载失败不能闪退。
- 单图上下滑换图；连续阅读控件默认隐藏，点按出现、再次点按或拖动隐藏；洗牌后无丢页、跳页，退出定位当前图片。
- GIF/动态 WebP 在单图和连续阅读中播放；普通图片不出现在问题媒体，故障视频保留在原页且不显示相邻视频旧画面。
- 锁定 2× 后一次下滑手势只执行取消，抬手保持用户原速度且页面不跟随位移。
- 验证按钮高度/透明度、卡牌阈值、特殊标记、一级子目录归并和短时扫描浮层的持久化及交互。

# v0.6.4 修复验证

- 将几十个文件加入永久删除后强制结束应用并重开：任务必须从已保存进度继续，已删除 URI 不得重新进入 Feed，任务中心可正常打开。
- 删除问题视频的同时进入剩余视频播放，验证无闪退、无相邻缩略图冒充；慢拖和连续切换重点观察首帧闪屏。
- 旧数据库升级后图片、GIF 和动态 WebP 不得出现在问题媒体；真正的视频故障项仍能筛选、停留、外部打开和删除。
- 图片页验证右侧点赞/收藏/浏览方式/更多，双击仅缩放；单图上下换图有过渡，瀑布流双击和捏合必须整条同步放大。
- 安装后检查普通图标、圆形图标及系统主题图标；按钮高度/透明度应同时改变视频页和图片页。
- 自动扫描在任务中心持续更新，主相册只短暂显示最终结果，30 秒内反复切回应用不得重复启动扫描。
