# v0.7.1 修复验证

- 在 100 GB 级目录继续复制文件时启动扫描：快速索引、元数据结束及任务中心关闭三个节点均不得闪退或长时间无响应。
- 扫描期间分别停留相册、任务中心、视频、单图和瀑布流；隐藏相册不得在后台突然整页重排，当前播放/阅读位置不得改变。
- 连续切换全部 12 种排序；弹窗应勾选当前规则、按钮应显示当前规则，完成后稳定定位第一项，无主线程卡死或闪退。
- 慢拖视频 30 次不得闪现上个视频首帧；快速连滑 30 次后只播放最终页，缩略图必须属于当前媒体且不得几秒后偷换页面。
- 导入仍未写完的视频不得进入可播放队列；文件稳定并在后续扫描读通元数据后才能出现。
- 任务中心同时保留千级永久删除目标并运行扫描；进度持续更新，退出重进可续跑，不能因每个文件同步写盘而明显拖慢。
- 制造系统内存压力后返回相册与播放器，缩略图可重新加载且应用不得因缓存不释放而退出。
- 单图和瀑布流均验证双指放大、缩小；瀑布流放大后左右移动响应明显，回到 1 倍可继续正常纵向阅读。
- 断开 GitHub API 或制造慢网络，检查更新应由清单线路成功或在短超时后明确失败，不能无限 timeout。
- 拖动进度条附近时不误暂停；铺满按钮只显示正方形外框，完整显示按钮仍保持原图形。
