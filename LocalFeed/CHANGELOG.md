# 0.5.1 播放恢复版

- 撤销 v0.5 的视频 poster / 首帧遮盖链路，恢复页面选中后立即切换单播放器。
- PlayerView 改为 TextureView，避免 ColorOS 上 SurfaceView 在 ViewPager 页面间转移时暴露黑帧。
- Feed 队列仅追加时不再 reset 预加载器，减少翻页附近重复准备媒体源。
- Feed 播放页隐藏底部导航和文件名遮挡，进度条贴底；右侧增加相册按钮。
- 返回键和相册按钮统一回到相册，并按当前视频 ID 定位；若筛选排除了当前视频，自动切回“全部”后定位。
- 横屏增加左上角返回按钮，隐藏竖屏右侧操作栏，返回后保持当前视频与进度。
- 长按 2× 下滑锁定后支持上滑撤销；锁定松手后保留可点击的取消入口。
