# 0.7.0 图片缩放与应用内更新版

- 视频右侧收藏下方新增纯图标画面按钮，单击在铺满与完整显示间切换并保存到当前视频；保留“更多”中的全局/单视频精细设置。
- 单图查看改为矩阵缩放，支持以双指中心连续缩放、放大后自由平移和双击复位；缩放状态不再与切图动画互相覆盖。
- 瀑布流保持整条阅读画布同步缩放，新增有边界的左右拖动；纵向仍由连续阅读列表负责，退出继续定位当前图片。
- 卡牌角标只显示等级名称，不再拼接累计点赞数字；播放页和图片页的大数使用紧凑格式。
- 主图标启用全新的 v0.7 资源编号并补齐五档传统密度、自适应、圆形与主题单色入口，减少桌面缓存旧图标。
- 使用 Android SplashScreen 兼容主题，将系统启动过渡改为纯黑无可见图案，不额外延长启动时间。
- “媒体库工具”增加检查更新；GitHub Release 提供固定签名 APK 和 SHA-256，系统下载服务负责跨进程下载，完成校验后进入系统安装确认。

# 0.6.4 删除恢复与图片交互版

- 永久删除和最近删除任务保存精确目标及逐文件完成点；应用被杀后自动从下一项续跑，旧版无法恢复的“进行中”记录会明确标为中断。
- 文件入队时立即从相册、Feed 和播放器映射中摘除；播放恢复为 v0.1/v0.4 的单播放器直接 MediaItem 路径，移除会握住已删除 SAF 文件的预加载源。
- 问题媒体只保留仍在媒体库中的视频，升级时清除历史图片误报和孤立记录；GIF/动态 WebP 继续按图片解码与播放。
- 图片查看改用视频同款右侧轨道：点赞、收藏、浏览方式、更多；双击只放大，删除、分享、外部打开和信息统一收进卡牌边框菜单。
- 单图上下切换加入轻量过渡；捏合缩放灵敏度和上限提高；瀑布流改为整条阅读画布同步缩放并支持双击放大/复位。
- 播放页的轨道高度和透明度同时作用于图片页；自动扫描进度只进入任务中心，完成结果才短暂显示，并增加返回应用后的扫描防抖。
- 启动图标改用新的资源名和可爱女孩图标，覆盖普通、自适应、圆形与主题单色入口，避免系统继续复用旧资源。

# 0.6.3 相册顺序与阅读体验修正版

- 排序完成后自动回到首项；从任何筛选、排序结果进入视频时，Feed 严格沿用当前可见顺序，主动进入 Feed 标签时才恢复随机。
- 修复任务中心读取已删除 SAF URI 时的崩溃风险，缩略图统一走安全的异步缓存加载并继续保存任务历史。
- 图片阅读器重做为漫画式沉浸控制：控件默认隐藏、点按唤出/收起、滑动时隐藏，新增洗牌；单图支持上下换图，瀑布流退出精确定位当前图片。
- 阅读页通过 ImageDecoder 播放 GIF/动态 WebP；普通图片元数据读取失败不再误报成问题媒体。
- 修复锁定 2× 在一次下滑手势内取消后又被重新锁定；切换问题视频前主动清除旧画面，避免相邻视频缩略图冒充当前文件。
- 当前播放项使用醒目边框和角标；播放页右侧按钮可同时调节轨道高度与透明度。
- 五档卡牌等级的点赞次数开放设置，新增独立特殊标记和动态图案；文件夹浏览按已导入根目录下的第一层子目录归并。
- 扫描结果改为短时半透明浮层，不再长期占据相册空间；启用原创可爱女孩 LocalFeed 图标。

# 0.6.2 阅读、诊断与任务中心版

- 修复随机相册在刷新时重复洗牌导致的瀑布流丢页、跳页和无法回到原图；连续阅读按屏幕中央图片返回相册定位。
- 瀑布流按图片比例预留稳定高度，支持双击放大/复位、捏合缩放和放大后拖动。
- 新增持久任务中心：扫描、诊断、重复检查、删除和最近删除显示进度、文件名、缩略图、完成或失败历史；播放期间不再弹扫描结果。
- 问题媒体成为相册筛选；区分已确认故障与待确认项目，播放失败停留原页并支持外部应用打开、查看信息和删除。
- 点赞改为可累加计数，提供铜辉、银曜、金耀、幻彩和典藏五级结构化边框及典藏册筛选；菜单继承对应等级边框。
- 播放按钮可沿右侧轨道调节高度并记忆；锁定倍速取消改为读取播放器真实状态。
- 文件信息只保留一个完整目录和有用属性；操作弹窗改为深色半透明圆角；新增 LocalFeed 自适应图标。

# 0.6.1 清理与图片修复版

- 横屏返回改为播放页全局悬浮按钮，不再依赖 ViewPager 页面复用状态；右侧操作区整体上移。
- 短视频每次从头播放，只有达到“长视频阈值”的视频才保存和恢复进度。
- 倍速下滑取消在抬手前持续拦截触摸，避免带动视频页面下移。
- 重复视频扫描完成后自动勾选待删除项；扫描与删除使用独立队列，失败项保留并显示结果。
- 状态合并完成后才开始删除，避免保留文件丢失点赞、收藏和观看信息。
- 问题媒体增加主动诊断：权限、空文件、图片解码、视频容器、时长、尺寸和视频轨道。
- 图片查看页支持直接永久删除；连续阅读显示读取失败原因，切换单图时重新加载当前图片。
- 连续阅读固定使用打开图片时的相册顺序，并从当前图片精确定位。

# 0.6.0 反馈修正版

- 慢速拖动时，相邻视频页先显示真实首帧缩略图，首个解码帧到达后再无缝移除，避免页面跟手阶段露出纯黑空洞。
- 进度条增加底部安全区与系统手势排除区域，修复从最近任务返回后拖动被系统手势抢走。
- 连续双击只会设为点赞并播放红心动画，不再反复取消点赞；单击暂停增加双击抑制窗口。
- 播放页永久删除成为主操作，文件处理期间先从 Feed 队列移除，避免黑屏和短暂复活；批量删除也支持永久删除。
- 横屏返回始终可见，播放页去除相册按钮与图标文字，增加全局/单视频铺满与完整显示记忆。
- 重复扫描改成分组清理流程：每组选择保留文件，合并点赞、收藏、观看次数和播放位置后批量永久删除。
- 相似视频扫描和单视频查找入口下线；问题媒体增加重试、相册定位、永久删除和清除记录。
- 默认完全均匀随机，可分别开启点赞、收藏、未看过的轻度倾向；移除“不再随机出现”。
- 新增播放位置记忆、相册当前项高亮、图片连续阅读模式。
- 扫描改成增量元数据分析；从其他应用返回时自动检查新增文件，并保存新增、更新、失败数量及最近导入文件名。

# 0.5.1 播放恢复版

- 撤销 v0.5 的视频 poster / 首帧遮盖链路，恢复页面选中后立即切换单播放器。

- 横屏增加左上角返回按钮，隐藏竖屏右侧操作栏，返回后保持当前视频与进度。
- 长按 2× 下滑锁定后支持上滑撤销；锁定松手后保留可点击的取消入口。
